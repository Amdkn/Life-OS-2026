# Categorie 9: B3 Polymorphic Matrix Engine

## Doctrine & Vision Fondamentale
Un agent B3 n est pas une entite figee ou un simple chatbot prompté. C est une fonction polymorphe adaptee a la realite du terrain :
B3 = f(Besoin en Intelligence, Besoin en Determinisme)

Selon les circonstances du domaine et la nature du probleme a resoudre, un B3 s incarne sous la forme la plus efficiente, ou sous une combinaison simultanee de formes :
1. **Skill** (Competence procedurale formalisee).
2. **Agent** (Raisonnement cognitif LLM autonome).
3. **Hook** (Intercepteur synchrone 5D a determinisme absolu).
4. **Cron** (Cadenceur temporel 4D en tache de fond).
5. **MCP** (Serveur / client de protocole d outils standardise).
6. **Plugin** (Module d extension d ecosysteme).
7. **CLI** (Script executif local ultra-rapide sans latence).
8. **API** (Point d entree programmatique asynchrone).
